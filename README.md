# BIM 4D Simulation

Combine **IFC 3D models** with **Primavera P6 schedules (XER)** for 4D construction simulation.

## ✨ Features

- 📁 **Import IFC** — Parse building models, render in WebGL via Three.js
- 📅 **Import XER** — Parse Primavera P6 schedules, display Gantt chart with WBS + dependencies
- 🔗 **Element-Task Linking** — Manual pick, box-select, or keyword-based auto-link
- ▶️ **4D Simulation** — Timeline playback, model appears/colors by construction progress
  - 🟢 Done (solid green)
  - 🟡 Active (semi-transparent yellow)
  - ⬜ Pending (hidden)
  - ⚫ Unlinked (semi-transparent gray)
- 🌳 **Model Tree** — Category-grouped element browser with show/hide toggles
- ⬡ **Box Select** — Drag-rectangle multi-select in 3D view
- 🎨 **Custom Colors** — Configurable state colors with live preview
- 💾 **Save / Load** — Export/import project state as `.bim4d` JSON
- 🖱️ **Standard Navigation** — Left-drag rotate, right-drag pan, scroll zoom
- ✏️ **Editable Tasks** — Double-click to edit task dates in Gantt, 4D syncs instantly

## 🚀 Quick Start

### Requirements
- **Python 3.10+** (tested on 3.14.6)
- Windows / macOS / Linux
- Modern browser (Chrome / Edge / Firefox)

### One-click (Windows)
```bat
double-click run.bat
```
Auto-installs dependencies, starts server, opens http://localhost:8000

### Manual
```bash
cd backend
python -m pip install -r requirements.txt
python main.py
```
Open http://localhost:8000

## 📖 Usage

1. **Import IFC** → 3D model appears
2. **Import XER** → Gantt chart shows schedule
3. **Auto Link** → keyword-based batch matching (Wall/Slab/Column etc.)
   - Or **Manual Link** → pick task in Gantt, then click/box-select elements in 3D
4. **Play** timeline → watch construction sequence
   - Drag slider to jump to any date
   - Click Gantt task → highlights linked elements in 3D
   - Click 3D element → locates linked task in Gantt
5. **Save Project** → exports `.bim4d` for later reload

## 🏗️ Tech Stack

| Layer | Tech | Notes |
|-------|------|-------|
| Backend | FastAPI + uvicorn | REST API |
| IFC Parse | IfcOpenShell 0.8.5 | Geometry + metadata |
| XER Parse | Custom parser | Primavera P6 format, UTF-8 support |
| 3D Render | Three.js r149 | WebGL, local vendor (offline) |
| Gantt | dhtmlxGantt v7 (GPL) | WBS tree + dependencies + timeline |

> **License note**: dhtmlxGantt is GPL — suitable for internal/prototype use. Replace or purchase a commercial license for distribution.

## 🔌 API

| Method | Path | Description |
|--------|------|-------------|
| POST | `/api/upload/ifc` | Upload IFC file |
| POST | `/api/upload/xer` | Upload XER file |
| GET | `/api/elements` | All element metadata |
| GET | `/api/element/{guid}/geometry` | Single element geometry |
| GET | `/api/tasks` | Task tree + dependencies |
| GET/POST/DELETE | `/api/link(s)` | Link management |
| POST | `/api/auto-link` | Auto-link suggestions / apply |
| GET | `/api/simulation?date=YYYY-MM-DD` | Element states for a date |

## 📝 Notes

- Links are stored in **memory** (lost on restart). Save your project with 💾 before closing.
- Large models (10k+ elements) may load slowly; LOD/batched geometry planned for future.
- Auto-linking relies on task names containing type keywords (Wall/Slab/Column etc.).
- Vendor libs (Three.js, dhtmlxGantt) are **included in the repo** for offline use.
